# 查看训练日志指南

## 日志位置

训练日志保存在 `./outputs/qwen3_vl_grounding_mvtec/logs/` 目录下。

## 日志类型

### 1. TensorBoard 日志（推荐）

训练使用 TensorBoard 记录训练过程，包括：
- **loss**（训练和验证损失）
- **learning_rate**（学习率变化）
- **训练步数**等指标

#### 查看方法

**方法1：使用 TensorBoard（推荐）**

```bash
# 安装 TensorBoard（如果未安装）
pip install tensorboard

# 启动 TensorBoard，指定日志目录
tensorboard --logdir ./outputs/qwen3_vl_grounding_mvtec/logs

# 或者指定端口
tensorboard --logdir ./outputs/qwen3_vl_grounding_mvtec/logs --port 6006
```

然后在浏览器中打开：`http://localhost:6006` 或 `http://你的服务器IP:6006`

**方法2：使用命令行查看最新日志**

```bash
# 查看最新的日志文件
ls -lt ./outputs/qwen3_vl_grounding_mvtec/logs/ | head -5

# 使用 tensorboard 的命令行工具查看（需要安装 tensorboard）
tensorboard --logdir ./outputs/qwen3_vl_grounding_mvtec/logs --host 0.0.0.0
```

### 2. 训练状态文件

训练过程中会生成 `trainer_state.json` 文件（在 checkpoint 目录中），包含：
- 训练步数
- 最佳模型路径
- 训练历史记录

```bash
# 查看训练状态
cat ./outputs/qwen3_vl_grounding_mvtec/checkpoint-*/trainer_state.json | python -m json.tool
```

### 3. 控制台输出

训练时的控制台输出会显示：
- 训练进度条
- 每个 step 的 loss
- 验证结果
- 保存 checkpoint 的信息

## 快速查看命令

### 查看最新的 TensorBoard 日志

```bash
# 启动 TensorBoard（后台运行）
nohup tensorboard --logdir ./outputs/qwen3_vl_grounding_mvtec/logs --port 6006 > /dev/null 2>&1 &

# 查看进程
ps aux | grep tensorboard
```

### 查看训练 checkpoint 信息

```bash
# 列出所有 checkpoint
ls -lh ./outputs/qwen3_vl_grounding_mvtec/checkpoint-*/

# 查看最新的 checkpoint 状态
find ./outputs/qwen3_vl_grounding_mvtec -name "trainer_state.json" -exec ls -lt {} + | head -1 | awk '{print $NF}' | xargs cat | python -m json.tool
```

### 实时监控训练日志

```bash
# 如果训练还在运行，可以实时查看输出
tail -f <训练日志文件>

# 或者使用 TensorBoard 实时查看
tensorboard --logdir ./outputs/qwen3_vl_grounding_mvtec/logs --reload_interval 5
```

## TensorBoard 界面说明

在 TensorBoard 界面中，你可以看到：

1. **SCALARS（标量）**：
   - `train/loss`：训练损失
   - `train/learning_rate`：学习率
   - `eval/loss`：验证损失（如果有验证集）

2. **GRAPHS（计算图）**：
   - 模型的计算图结构

3. **HISTOGRAMS（直方图）**：
   - 参数分布（如果启用）

## 常见问题

### Q: TensorBoard 无法访问？

**A:** 如果是远程服务器，需要：
1. 使用 SSH 端口转发：
   ```bash
   ssh -L 6006:localhost:6006 user@server
   ```
2. 或者使用 `--host 0.0.0.0` 让 TensorBoard 监听所有接口

### Q: 如何查看特定 checkpoint 的日志？

**A:** 每个 checkpoint 目录下可能有独立的日志，可以：
```bash
tensorboard --logdir ./outputs/qwen3_vl_grounding_mvtec/checkpoint-100/logs
```

### Q: 如何导出日志数据？

**A:** 可以使用 TensorBoard 的导出功能，或者直接读取 JSON 文件：
```bash
# 查看 trainer_state.json
cat ./outputs/qwen3_vl_grounding_mvtec/checkpoint-*/trainer_state.json | python -m json.tool | grep -A 10 "log_history"
```

## 日志文件说明

- `events.out.tfevents.*`：TensorBoard 事件文件，包含所有训练指标
- `trainer_state.json`：训练状态文件，包含训练历史和配置
- `training_args.bin`：训练参数配置（二进制格式）
