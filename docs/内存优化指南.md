# 内存优化指南

## 常见内存不足问题

训练过程中出现内存不足（OOM）的常见原因：

1. **图像数据占用**：大图像和图像tensor占用大量内存
2. **梯度累积**：梯度累积会保留多个batch的梯度
3. **TensorBoard图像缓存**：保存评估图像到TensorBoard会占用内存
4. **数据加载器缓存**：数据加载器可能缓存数据
5. **模型中间状态**：训练过程中保留的计算图

## 已实现的优化

### 1. 自动内存清理
- 图像处理后立即释放
- 每100步自动清理CUDA缓存
- 评估后清理临时变量

### 2. 可配置的优化选项

#### 禁用评估图像保存（节省大量内存）
```bash
# 默认不保存图像，只保存文本摘要
# 如果需要保存图像，设置环境变量：
SAVE_EVAL_IMAGES=true python qwen3_vl_8b.py [参数...]
```

#### 禁用梯度范数计算（节省少量内存）
```bash
# 默认启用梯度范数计算
# 如果内存紧张，可以禁用：
DISABLE_GRAD_NORM=true python qwen3_vl_8b.py [参数...]
```

### 3. 数据加载优化
- `dataloader_pin_memory=False`：关闭pin_memory节省内存
- `dataloader_prefetch_factor=2`：减少预取因子

## 内存优化建议

### 方案1：减小图像尺寸（最有效）

```bash
# 从1024减小到512可以节省约75%的图像内存
--max_image_size 512  # 而不是1024
```

### 方案2：减小batch size，增加梯度累积

```bash
# 保持总有效batch size不变
--batch_size 1  # 减小
--gradient_accumulation_steps 32  # 增加（原来是16）
```

### 方案3：使用DeepSpeed（推荐）

```bash
# DeepSpeed可以分片存储模型和优化器状态
torchrun --nproc_per_node=2 qwen3_vl_8b.py \
    --deepspeed scripts/zero2.json \
    [其他参数...]
```

### 方案4：禁用不必要的功能

```bash
# 禁用评估图像保存
SAVE_EVAL_IMAGES=false python qwen3_vl_8b.py [参数...]

# 禁用梯度范数计算
DISABLE_GRAD_NORM=true python qwen3_vl_8b.py [参数...]
```

### 方案5：减少数据加载器workers

```bash
# 减少workers可以节省内存
--num_workers 2  # 而不是4
```

## 内存使用估算

### 单GPU训练（Qwen3-VL-8B）

- **模型参数（BF16）**: ~16GB
- **优化器状态（AdamW）**: ~32GB（如果全参数训练）
- **LoRA参数**: ~0.1GB
- **LoRA优化器状态**: ~0.2GB
- **图像数据（batch_size=1, 1024x1024）**: ~0.1GB/batch
- **梯度累积（16步）**: ~0.1GB × 16 = ~1.6GB
- **激活值（gradient checkpointing）**: ~2-4GB
- **TensorBoard缓存**: ~0.5-1GB

**总计（LoRA训练）**: ~20-25GB

### 多GPU训练

使用DeepSpeed Zero-2可以显著减少内存：
- **每GPU模型参数**: ~4-8GB（分片）
- **每GPU优化器状态**: ~8-16GB（分片）
- **其他**: 类似单GPU

### 如果出现OOM错误

代码会自动提供建议：
1. 减小batch_size
2. 增加gradient_accumulation_steps
3. 减小max_image_size
4. 使用DeepSpeed
5. 禁用评估图像保存
6. 禁用梯度范数计算

## 常见问题

### Q: 为什么训练一段时间后内存不足？

**A:** 可能原因：
1. TensorBoard缓存累积
2. 数据加载器缓存
3. 梯度累积导致的内存累积
4. 图像处理缓存

**解决方案**：
- 使用DeepSpeed
- 减小图像尺寸
- 定期清理缓存（代码已实现）

### Q: 如何知道是哪个部分占用内存？

**A:** 使用`nvidia-smi`监控，或者：
```python
# 在代码中添加内存监控
import torch
print(f"GPU内存使用: {torch.cuda.memory_allocated() / 1024**3:.2f} GB")
print(f"GPU内存缓存: {torch.cuda.memory_reserved() / 1024**3:.2f} GB")
```

### Q: DeepSpeed真的能节省内存吗？

**A:** 是的，DeepSpeed Zero-2/3可以：
- Zero-2: 分片优化器状态，节省约50%内存
- Zero-3: 分片模型参数和优化器状态，节省约75%内存
